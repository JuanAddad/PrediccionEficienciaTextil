## Predicción de empleados de Empresa Textil — Learning Project
Dataset: Kaggle — Factory workforce (411K observations, 18 months)

### Objetivo
Predecir la eficacia esperada de operarios de una fábrica textil a partir 
de variables como edad, salud, rol, supervisor y patrones temporales.

### Metodología
- EDA univariado y multivariado
- Análisis estadístico (t-test, correlación)
- Feature engineering
- Modelos: Regresión Lineal → Random Forest → XGBoost
- Métrica final: MAE = 0.26 (7% del rango total)

### Librerías
pandas · matplotlib · seaborn · scipy · scikit-learn · XGBoost
